## 0. 요약

V3의 목표는 **"공기질 기록기"를 "출력 안전 시스템"으로 바꾸는 것**이다.

1. **발생원과 노출을 분리 측정** — 프린터 챔버/배기구 프로브 + 실내 허브의 2지점 측정
2. **측정 범위 확장** — 초미세입자(UFP) 지표, VOC 원시 신호, 일산화탄소(CO) 추가
3. **화재 징후 감지** — 열화상(MLX90640) + CO + 입자 급증의 다중 조건 판정
4. **네트워크 없이 동작하는 로컬 경보·차단** — 부저·디스플레이·스마트 플러그 전원 차단
5. **측정 이상의 분석** — 출력 1회 단위 배출 리포트, 환기율·배출률 추정, 필라멘트별 비교

> ⚠️ V3도 **인증 화재감지기나 경보기를 대체하지 않는다.** 인증된 감지기(단독경보형 감지기 등)와 소화기는 별도로 갖춘다.

## 1. v2의 측정 한계 — V3가 넘어야 할 것

| # | v2 한계 | 원인 | V3 대응 |
|---|---|---|---|
| L1 | **초미세입자를 거의 측정하지 못함** | PMS7003 하한 0.3 µm. FDM 출력 입자는 대부분 0.1 µm 이하(입자 수 기준, Stephens 2013·Azimi 2016) | 입자 **수** 농도 채널 추가(SEN66), **0.1 µm 채널** 지표(IPS-7100, C 등급) |
| L2 | **VOC가 상대 지수뿐** | SGP41 VOC Index는 학습된 기준선 대비 값. 기준선 갱신 정지(게이팅)는 최대 180분이라 장시간 출력 중 VOC가 기준선에 흡수됨 | 원시 신호(SRAW) 기록, 게이팅 시간 연장, BME688 가스 패턴(실험), PID 절대 농도(옵션) |
| L3 | **한 지점만 측정** | 실내 1곳 측정이라 배출원과 노출을 구분할 수 없음 | 챔버/배기 프로브 + 실내 허브 **차분 측정** |
| L4 | **상황 정보 없음** | 출력 중인지, 어떤 필라멘트인지 모름 | 전력 계측 플러그로 출력 상태 판정, (선택) Bambu LAN 연동 |
| L5 | **화재 징후 감시 없음** | v1의 CO 센서를 v2에서 제거함. 열 감시 없음 | CO(전기화학) + 열화상 + 다중 조건 판정 |
| L6 | **장치 자체 경보 없음** | 경보를 클라우드·앱에만 의존 | 부저·LED·디스플레이 + 네트워크와 무관한 안전 태스크 |
| L7 | **데이터 경로 제약** | ThingSpeak 15초 간격·8필드·클라우드 의존, 로컬 저장 없음 | 로컬 우선(MQTT + Home Assistant), microSD 1 Hz 원시 로그, ThingSpeak는 보조 |
| L8 | **품질 관리 없음** | 교정·결측 표시·센서 수명 관리 없음 | 모든 값에 품질 플래그, 교정 절차, 수명 알림 |
| L9 | **케이스가 측정을 왜곡** | PLA, 발열부와 센서가 한 공간, PMS 흡·배기 미분리 | 2구역 분리, 흐름 경로 설계, PETG |

## 2. 요구사항과 수용 기준

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| R1 | 실내 노출 측정 | PM1/2.5/4/10 질량, 입자 수(0.5–10 µm), T/RH, VOC/NOx Index + SRAW, CO2, HCHO, CO를 1 Hz로 기록 |
| R2 | 발생원 측정 | 챔버/배기 지점의 PM, VOC, T/RH를 허브와 같은 시간축으로 기록 |
| R3 | 화재 징후 판정 | 모의 시험(§10)에서 조건 충족 후 **10초 안에** 위험 단계 진입 |
| R4 | 로컬 경보 | Wi-Fi·서버를 끊어도 경보와 전원 차단이 동작. 부저 85 dB 이상(10 cm) |
| R5 | 데이터 품질 | 모든 값에 OK/WARMUP/STALE/FAULT 상태 부여. 결측을 숫자로 대체하지 않음. 센서를 분리하면 30초 안에 FAULT |
| R6 | 데이터 보존 | microSD에 1 Hz 원시 로그 30일 이상. 네트워크 복구 후 MQTT로 백필 |
| R7 | 보안 | 소스에 비밀값 없음, 모든 원격 전송 TLS, Wi-Fi 프로비저닝, 서명된 OTA |
| R8 | 출력 리포트 | 출력 시작·종료 자동 감지. 1회당 피크·평균 증가분·노출량·추정 배출률 요약 |
| R9 | 유지보수 | 교정 절차 문서, 센서 수명·교정 주기 알림, OTA 업데이트 |
| R10 | 전기 안전 | 상용 전원(220 V)을 직접 스위칭하는 회로를 만들지 않고 KC 인증 스마트 플러그만 사용 |

## 3. 시스템 구성

```
 ┌──────── 챔버/배기 프로브 (ESP32-C6) ────────┐        ┌──────────── 실내 허브 (ESP32-S3) ────────────┐
 │ SEN65: PM·VOC/NOx·T/RH                      │        │ SEN66: PM 질량·입자 수·T/RH·VOC/NOx·CO2       │
 │ MLX90640 55°: 베드·툴헤드 열화상             │─ESP-NOW→│ SFA30: HCHO   ZE07-CO: CO   BME688(B)         │
 └─────────────────────────────────────────────┘ (암호화) │ IPS-7100: 0.1 µm 입자(C)   PID(옵션)          │
                                                         │ 2.8" 디스플레이·부저·RGB LED·버튼·microSD     │
                                                         └───────┬───────────────────────┬───────────────┘
                                                                 │ MQTT/TLS              │ 로컬 API
                                                   ┌─────────────▼──────────┐   ┌────────▼───────────────┐
                                                   │ 홈서버(선택)           │   │ 전력 계측 스마트 플러그 │
                                                   │ Mosquitto · Home       │   │ (출력 상태 판정·차단)   │
                                                   │ Assistant · InfluxDB   │   │ 공기청정기/배기 제어    │
                                                   └────────────────────────┘   └─────────────────────────┘
                                                   ThingSpeak(HTTPS, 보조) · 푸시 알림(텔레그램 등)
```

| 노드 | 위치 | 역할 |
|---|---|---|
| 실내 허브 | 프린터에서 1–2 m, 호흡 높이(약 1.0–1.2 m), 배기구 정면은 피함 | 노출 측정, 경보·표시, 판정, 로그, 외부 연동 |
| 챔버/배기 프로브 | P1S 챔버 내부 또는 후면 배기구(현물 확인 후 결정) | 발생원 측정, 열화상 |
| 스마트 플러그 | 프린터 전원 | 전력으로 출력 상태 판정, 위험 단계에서 차단 |
| 홈서버(선택) | 기존 PC/NAS 또는 라즈베리파이 | 장기 저장, 대시보드, 자동화 |

## 4. 하드웨어 — 부품

### 4.1 센서 (v2 → V3)

| 측정 | v2 | V3 | 개선 내용 | 등급 |
|---|---|---|---|---|
| PM | PMS7003 (0.3–10 µm, 질량) | **SEN66** (PM1/2.5/4/10 질량 + 입자 수) | 입자 수 농도, I2C 단일 버스 | A |
| 초미세입자 | 없음 | **IPS-7100** (0.1–10 µm, 7채널) | 0.1 µm 채널. 제조사 인증은 PM1.0 기준으로 표기되어 있어 **지표로만** 사용 | C |
| T/RH | SHT41 | SEN66 내장 + 흡기 유로 배치 | 발열부와 분리해 온도 편향 감소 | A |
| VOC | SGP41 (VOC Index) | SEN66 내장 VOC/NOx + **SRAW 기록·게이팅 연장** | 장시간 출력에서도 추세 유지, 사후 재분석 가능 | A |
| VOC 패턴 | 없음 | **BME688** (가열 프로파일 기반 가스 패턴) | 필라멘트·이소프로필알코올 등 상황 분류 실험 | B |
| VOC 절대 농도 | 없음 | **PID** (Alphasense PID-AH2급) | ppb 단위 TVOC(이소부틸렌 환산) | 옵션 |
| CO2 | MH-Z16 (NDIR, PWM) | SEN66 내장 CO2 (I2C) | PWM 오판독 제거, 환기 추적자로 활용 | A |
| HCHO | ZE08-CH2O | **SFA30** (전기화학, ±20 ppb 또는 ±20%) | RH/T 보상, 교차 감도 감소 | A |
| CO | 없음(v1에만 있었음) | **ZE07-CO** (전기화학 0–500 ppm, UART 3 V) | 훈소·연소 초기 징후 | A |
| 열 | 없음 | **MLX90640 55°** (32×24, −40–300 °C) | 비정상 열점·온도 상승률 감지 | B |
| 출력 상태 | 없음 | 전력 계측 스마트 플러그 | 대기·가열·출력·냉각 구분 | A |

- **SEN6x 계열 호환:** SEN6x는 SEN62/63C/65/66/68/69C가 같은 외형을 공유한다고 알려져 있다(제3자 사양, 데이터시트 확인 필요). 인클로저를 SEN6x 외형 기준으로 설계하면, 가격이 맞을 때 HCHO가 내장된 **SEN68·SEN69C**로 바꿔 SFA30을 뺄 수 있다.
- **열화상 설치:** 장파 적외선은 유리·아크릴을 투과하지 못하므로 MLX90640은 **챔버 안**에 둔다. 30 cm 거리에서 55° 화각은 가로 약 31 cm를 덮고 픽셀당 약 1 cm다. 노즐은 픽셀보다 작아 실제보다 낮게 읽히므로, 판정은 **여러 픽셀에 걸친 열점** 기준으로 한다.

### 4.3 액추에이터·연동

- **프린터 전원:** KC 인증 전력 계측 스마트 플러그(로컬 API: MQTT/HTTP 또는 Matter)를 쓴다. 출력 상태 판정과 위험 단계 차단을 맡는다. 전력 임계값은 현물을 측정한 뒤 정한다.
- **저감 장치:** 기존 IoT 플러그·Home Assistant로 공기청정기를 켜고 끈다. C 등급은 P1S 배기구용 필터 박스(HEPA H13 + 활성탄)와 12 V PWM 팬을 허브가 직접 제어한다.
- **Bambu Lab 연동(선택):** LAN Only 모드의 Developer Mode에서 MQTT로 출력 단계와 필라멘트 정보를 받을 수 있다. 다만 제조사가 공식 지원하지 않는 기능이라 **필수 기능에서 제외**하고, 전력 기반 판정을 기본으로 한다.

| 예상 크기 | 약 140 × 100 × 60 mm (부품 확정 후 결정) |

### 5.3 챔버/배기 프로브·열화상 브래킷

- **프로브 하우징:** 약 70 × 45 × 30 mm(추정), 공기가 관통하는 유로형. PETG가 기본이고, 챔버가 상시 60 °C를 넘으면 ASA를 쓴다. ASA는 스티렌을 방출해 VOC 측정에 편향을 줄 수 있으니 충분히 환기한 뒤 사용한다.
- **열화상 브래킷:** 볼조인트로 각도를 조절하며, 챔버 상단 전면 모서리에 두어 베드 전체가 화각에 들어오게 한다.
- **설치:** P1S를 실측한 뒤 VHB 테이프나 클립 방식으로 정한다. 프린터 본체 천공·개조는 피한다.

### 5.4 CAD 산출물 규칙

- **원본:** Fusion 360(.f3d) 파라메트릭 모델. 벽 두께·공차·센서 외형은 사용자 파라미터로 관리
- **배포:** 파트별 STEP·3MF와 조립도(PNG/PDF). 파일명은 `v3_<part>_r<rev>` 형식(v2의 `Quailty` 같은 오타 방지)
- **위치:** `hardware/v3/cad/`

## 6. 펌웨어 설계

### 6.1 구조

- **빌드:** PlatformIO + Arduino-ESP32 3.x. `platformio.ini`에 라이브러리 버전 고정
- **FreeRTOS 태스크:**
  - `SafetyTask` — 최우선 순위, 네트워크와 무관하게 경보 판정·차단
  - `SensorTask` — 센서별 주기 측정
  - `NetTask` — Wi-Fi·MQTT를 논블로킹으로 유지, 지수 백오프 재접속
  - `LogTask` — microSD 기록
  - `UiTask` — 화면·LED·버튼
  - `ProbeLinkTask` — ESP-NOW 수신
- **공통 라이브러리 `lib/core`:** 측정 데이터 모델, 품질 판정, 경보 상태기계, 배출 분석. 하드웨어와 분리해 **PC에서 단위 테스트**

### 6.2 데이터 모델

- 각 값은 `{ value, timestamp, quality }` 구조
- `quality`는 OK, WARMUP, STALE, FAULT, OUT_OF_RANGE, CALIBRATING 중 하나
- STALE 기준은 센서별 예상 주기 × 3
- 결측은 null로 전송하거나 생략한다. **숫자 센티널(-1, 0) 금지**
- MQTT 토픽 스키마에 버전을 넣는다(`printer-safety/v3/...`). v1→v2에서 field3·field4 의미가 바뀐 것 같은 혼선을 막기 위함

### 6.3 보안

| 대상 | 방식 |
|---|---|
| 자격 증명 | 소스에 넣지 않음. BLE 또는 캡티브 포털로 프로비저닝한 뒤 NVS에 저장(NVS 암호화 선택) |
| 전송 | 원격은 MQTT over TLS, 로컬 브로커는 계정 인증. HTTPS는 루트 CA 고정 |
| 노드 간 | ESP-NOW 유니캐스트 암호화(LMK) + 페어링 고정 |
| OTA | HTTPS 배포 + 이미지 서명 검증. Secure Boot·Flash Encryption은 eFuse가 되돌릴 수 없으므로 별도 절차로만 적용 |

## 7. 안전 로직 — 경보 단계

판정 원칙:
- 여러 조건을 함께 본다.
- 지속 시간과 히스테리시스를 두어 깜빡임을 막는다.
- 출력 상태를 맥락으로 쓴다.
- **센서 FAULT를 '정상'으로 표시하지 않는다.**

아래 수치는 **초기값**이며 현장 측정 후 조정한다.

| 단계 | 조건(예) | 동작 |
|---|---|---|
| 정상 | 모든 값이 기준 이하 | 녹색 표시 |
| 주의 | 실내 PM2.5 10분 평균 ≥ 36 µg/m³(환경부 '나쁨'), HCHO ≥ 80 ppb(WHO 0.1 mg/m³), VOC Index ≥ 200, CO2 ≥ 1,000 ppm, CO ≥ 9 ppm | 공기청정기 ON, 알림 |
| 경고 | PM2.5 ≥ 76 µg/m³('매우나쁨'), HCHO ≥ 160 ppb, VOC Index ≥ 300, CO ≥ 30 ppm(WHO 1시간 기준 35 mg/m³) | 배기 ON, 부저 단속음, 알림 |
| 위험(화재 의심) | 강한 지표 1개 또는 중간 지표 2개 이상이 2분 안에 발생 — 강한 지표: 노즐 영역 밖 2픽셀 이상 ≥ 200 °C / 중간 지표: CO 2분 내 +10 ppm, 출력하지 않는데 입자 수 1분 내 5배, 챔버 온도 상승률이 정상 범위 초과 | 부저 연속음, **프린터 전원 차단**, 긴급 알림(열화상 스냅샷 포함) |
| 센서 이상 | 핵심 센서가 30초 이상 STALE/FAULT | 황색 표시, '센서 고장' 알림 |

- **기준값 출처:** PM2.5 등급은 환경부의 일평균 예보 등급을 단기 판정에 빌려 쓴 값이다. CO 9 ppm은 WHO 8시간 기준(10 mg/m³), 30 ppm은 1시간 기준(35 mg/m³)을 ppm으로 환산한 값이다.
- **열화상 정상 범위:** 처음 몇 차례 정상 출력에서 영역별 최고 온도를 학습해 기준으로 삼는다.
- **차단의 부작용:** 전원을 끊으면 출력물이 손실되므로 차단은 위험 단계에서만 한다.

## 8. 데이터·분석 — 측정을 넘어서는 기능

| 기능 | 방법 | 결과 |
|---|---|---|
| 출력 이벤트 분할 | 전력 패턴(가열 → 출력 → 냉각)으로 시작·종료 감지, 버튼으로 필라멘트 태그 | 출력 단위 데이터셋 |
| 출력 리포트 | 출력 전 기준선 대비 피크·평균 증가분·누적 노출량(µg/m³·h, #/cm³·h) | 출력 1회 요약 알림 |
| 환기·여과율 추정 | 출력 종료 후 입자 농도 감쇠를 지수 함수로 맞춤 → 손실률 k(h⁻¹)·반감기 | "환기 시 PM 반감기 N분" |
| 배출률 추정 | 물질수지 `E(t) = V·[dC/dt + k·(C − C_bg)]` (V: 방 체적) | 입자/분, µg/분. UL 2904 시험법 개념을 실내에 근사 적용한 것이며 정밀 시험이 아님 |
| 발생원·노출 비교 | (실내 증가분) ÷ (챔버 증가분) = 누설 비율. 필터 장착 전후 비교 | 저감 효과 정량화 |
| 필라멘트별 통계 | 태그된 출력별 배출 지표 집계 | 재료 선택 근거 |
| 조기 경보 | 상승률(dC/dt) 기반 예측 | 임계값 도달 전 알림 |

|---|---|---|
| 신형 센서 재고·리드타임 | 일정 지연 | SEN6x 공통 외형으로 대체 모델 허용, 조기 주문 |
| 열화상 오탐(반사·방사율) | 불필요한 차단 | 정상 출력 학습, 다중 조건, 차단 전 단계적 경보 |
| 챔버 고온에서 센서 정확도 저하 | 발생원 수치 편향 | 배기구 설치 대안, 온도 보정, 사양 범위 밖 데이터 표시 |
| 인클로저 출력물의 VOC 방출 | 초기 VOC 기준선 오염 | PETG 사용, 48–72시간 환기 후 설치 |
| Bambu 펌웨어 정책 변경 | 프린터 연동 불가 | 전력 기반 판정을 기본으로 사용 |
| 상용 전원 개조 위험 | 감전·화재 | 인증 스마트 플러그만 사용, 직접 릴레이 제작 금지 |
| 인증 장비로 오인 | 안전 공백 | 문서·화면에 '보조 장치' 명시, 인증 감지기 병행 |

## 15. 결정이 필요한 사항

1. 예산 등급: **B 권장**
2. 홈서버 유무: 기존 PC/NAS를 쓸 수 있는지
3. 프로브 설치 위치: 챔버 내부 또는 배기구(P1S 실측 후)
4. 프린터 연동: 전력 기반만 쓸지, Bambu LAN 모드까지 쓸지
5. v2 센서 재사용 여부
